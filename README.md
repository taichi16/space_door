# 🚀 Space Door Airlock Portal (太空艙門入口)

電影級擬真科幻太空艙氣密門驗證入口系統。採用純前端技術（HTML5、CSS3、Web Audio API 與 Canvas 粒子系統）打造，具備沉浸式工業裝甲艙門、門框一體化實體「開」按鈕、天花板實體全息投影投射儀、減壓氣爆白霧、第一人稱平穩出艙漫步視角，以及太陽系深空全景（地球、月球、火星三大天體同框與科技鎖定 HUD）。

---

## 🌟 特色功能 (Key Features)

### 1. 工業裝甲氣密門與一體化「開」按鈕 (Armor Door & Integrated Push-Button)
- **噴漆舊化標誌**：門扇中央噴印綠白相間的工業舊化風格 ETC 標誌（方案 A 擬真噴漆塗裝）。
- **門框一體化實體「開」按鈕**：
  - 於右側固定門框裝甲柱精確對位嵌入金屬圓形實體按鈕，材質與光影與門框無縫融合。
  - 具備環狀青藍霓虹脈衝光暈（Pulse Glow）與擬真機械微凹按壓回饋。
  - 點擊按鈕可隨時手動自天花板降下並展開全息帳密認證投影。
- **分層機械結構**：外部固定重型裝甲門框（Outer Bulkhead Frame）與內部雙扇滑動門（Inner Sliding Leaves）分層運作，驗證通過時僅內部兩扇門板向兩側滑入門框收納凹槽，外部門框維持穩固。

### 2. 天花板全息投影機構 (Retractable Overhead Projector)
- **實體投射燈具**：天花板中央具備實體發光鏡頭與旋轉雷達環，投射出向下擴展的錐形體積光束（Volumetric Light Cone）。
- **自動延遲投影**：網頁載入 1 秒後，自動降下投射全息認證面板。
- **嚴格符合機械邏輯**：驗證成功後，全息 HUD 迅速消散，投影機組 100% 垂直滑升縮回天花板收納槽；全息面板右上角亦配備收回按鈕（✕），隨時可手動收納投影、完整欣賞大門全貌。

### 3. 第一人稱視角平穩出艙推進 (First-Person Smooth EVA Spacewalk)
- **人走出去艙門的真實視角**：內門完全開啟後，鏡頭如同太空人邁開腳步跨出氣密門步入浩瀚深空。
- **全幅無黑邊設計（Zero Black Borders）**：
  - 深空背景總成以 108% 超滿版全景視野鋪滿。
  - **在開關門滑動、人員出艙推進或退回艙內的全過程中，100% 杜絕任何黑邊、黑框或裁切縫隙**。
- **電影級極致平穩（Zero Wobble & Shake）**：
  - 完全消除視角晃動、上下顛簸與步態旋轉，改採對稱純淨的電影推軌曲線（`cubic-bezier(0.22, 1, 0.36, 1)`）。
- **太陽系三大天體完整同框（地球、月球、火星）**：
  - 推進時畫面居中平滑放大至 1.14x，左側地球、中間月球、右側火星**三顆天體全景全數完整保留於螢幕內，火星絕不消失**！
- **退回艙門內部（RE-SEAL AIRLOCK）**：
  - 步入深空後浮現「⮌ 退回艙門內部」控制列，點擊後鏡頭平穩倒退縮回艙內（1.14x ➔ 1.0x），兩扇裝甲門合攏鎖定，投影機組重新滑下投射。

### 4. 三大天體全息科技鎖定 HUD (Celestial Target Reticles)
步入深空後，滑鼠游標可分別移至各天體盤面進行掃描與鎖定互動：
- **月球 (Luna)**：懸停鎖定 ➔ 浮現「**案件管理系統**」發光標籤、閃爍直角框線與雷達掃描光刀。
- **地球 (Earth)**：懸停鎖定 ➔ 浮現「**報告產生器**」發光標籤、科技直角框線與掃描光束。
- **火星 (Mars)**：懸停鎖定 ➔ 浮現「**火星觀測站**」發光標籤與科技鎖定框線。
- 配備 Web Audio 程序化鎖定音律與點擊反饋。

### 5. 物理氣爆白霧與程序化音效 (Steam Jets & Web Audio API)
- **洩壓蒸氣模擬**：HTML5 Canvas 即時動態模擬氣密閥減壓白霧噴射（Decompression Steam Burst）。
- **純 Web Audio 合成音效**：內建高低頻氣密洩壓嘶嘶聲、磁力靴踏步聲、開關門重低音頻、全息操作音、授權成功音律與報警音，**零外部音頻檔案依賴**。

## 🔑 預設登入憑證 (Credentials)

您可以在全息介面中直接輸入，或點擊介面上的快速登入按鈕：

| 角色 / 按鈕 | 帳號 (Security ID) | 密碼 (Passcode) | 說明 |
| :--- | :--- | :--- | :--- |
| **宇宙領航員** | `commander` | `earth-2026` | 指揮官特權身分，開門並執行出艙漫步 |
| **星際訪客 (測試錯誤)** | `visitor` | `guest-9999` | 錯誤憑證，觸發門頂紅燈警報與警示音 |

> 💡 **操作指南**：
> 1. 載入網頁 1 秒後全息面板自動展開，亦可點選全息面板右上角「✕」收回投影，或點擊門框右側金屬「**開**」按鈕手動展開。
> 2. 輸入正確帳密或點選「宇宙領航員」後按下 Enter 或點擊「驗證通行憑證」，艙門解鎖、投影機縮回天花板、噴出白霧後雙門滑開，鏡頭平穩推進至深空。
> 3. 進入深空後，滑鼠移至**地球、月球、火星**盤面可觸發科技鎖定 HUD。
> 4. 點擊畫面中央下方的「**⮌ 退回艙門內部 (RE-SEAL AIRLOCK)**」，鏡頭平穩縮回艙內，大門關閉並重新降下投影面板。

## 💻 快速開始 (Quick Start)

本專案為純原生前端單頁應用，無需任何建置工具、打包步驟或 Node.js 後端：

1. **取得程式碼**：
   ```bash
   git clone https://github.com/taichi16/space_door.git
   cd space_door
   ```

2. **直接執行**：
   - 在 macOS 上：
     ```bash
     open index.html
     ```
   - 或透過本機 HTTP 伺服器預覽：
     ```bash
     python3 -m http.server 8080
     # 於瀏覽器開啟 http://localhost:8080/index.html
     ```
